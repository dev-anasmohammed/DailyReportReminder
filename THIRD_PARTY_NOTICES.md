https://www.flaticon.com/free-icon/notes_16945811

https://cdn-icons-png.flaticon.com/512/16945/16945811.png

The source page could not be retrieved automatically to verify the creator credit; this source notice does not replace any creator attribution required by that license.

Desktop icon assets are resized versions of this PNG. Launcher icons and the Windows tray icon use a white background for visibility; the macOS menu-bar icon uses the transparent image as a template.

Run tools/update_icons.ps1 on Windows to regenerate platform assets.
